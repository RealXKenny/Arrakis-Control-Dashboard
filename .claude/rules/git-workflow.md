# Git workflow
- Check branch, working tree and diff before editing; never overwrite unrelated work.
- Prefer scoped conventional commits (`feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `perf:`, `security:`, `chore:`).
- Stage only files belonging to the task. Do not stage `.env`, credentials, generated build/test artifacts or caches.
- Ask before commit, push, merge, rebase, branch deletion, force push or deployment.
- Never bypass branch protection, required CI, or security checks.
- Review the final diff and disclose unresolved failures and unverified assumptions.
- Do not delete `AGENTS.md` or alter its Next.js-generated managed block.
