# Engineering conventions

Prefer minimal, domain-owned changes; preserve naming and dependency boundaries; use TypeScript types at API boundaries; validate external payloads as `unknown`; avoid introducing unrequested dependencies or persistent stores. Follow the existing Obsidian/Sand/Spice UI system, accessible navigation, responsive layout, and reduced-motion behavior. For Next.js 16 behavior, read the installed Next.js documentation as required by `AGENTS.md`.
