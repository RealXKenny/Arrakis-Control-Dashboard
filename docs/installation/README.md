# Installation

| Guide                                    | Use it when                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------ |
| [Local development](local-development.md) | You want to run or change the code on your computer                                        |
| [Production (Linux and Windows)](production.md) | You host the dashboard with Node.js directly                                         |
| [Pterodactyl](pterodactyl.md)            | You host through a Pterodactyl panel using the generated egg                                |
| [Reverse proxy](reverse-proxy.md)        | HTTPS in front of the app: Nginx, Cloudflare, `TRUSTED_PROXY_COUNT`                         |
| [Updating](updating.md)                  | Moving to a newer release                                                                   |

For the full path including the game server, see [End-to-end setup](../getting-started/end-to-end-redblink-setup.md).

## Deployment methods that exist

| Method                         | Status                                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Node.js directly (`npm start`) | Supported (Linux, Windows)                                                                                      |
| Pterodactyl egg                | Supported; generated by `scripts/deployment/build-pterodactyl-egg.mjs` and attached to each GitHub Release      |
| Docker image / Compose file    | **Not provided.** The old container image and Compose files were removed; there is no GHCR package to pull       |
| Kubernetes / serverless        | Not provided. The app needs a long-running Node.js process and shared Redis                                      |

> **Docker note.** RedBlink Dune Docker uses Docker for the *game server*; that is a different project. The dashboard
> itself does not ship a Dockerfile. If you containerize it yourself, you own that image's security and updates.

## Every installation needs

1. The production variables in [environment variables](../configuration/environment-variables.md).
2. Redis ([Redis](../configuration/redis.md)).
3. A Discord application ([Discord OAuth](../configuration/discord-oauth.md)).
4. HTTPS ([reverse proxy](reverse-proxy.md)).
